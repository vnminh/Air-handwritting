# Example trajectories

These three CSV files are held-out trajectories from the VNI Air Writing Dataset
and contain the `x,y` coordinate columns expected by the inference API.

- `bao_gio.csv`: reference `bao giờ`; paper-checkpoint prediction `bao giờ`.
- `ngon_nui_cao_voi_voi.csv`: reference and paper-checkpoint prediction
  `ngọn núi cao vời vợi`.
- `bi_failure.csv`: reference `bí`; paper-checkpoint prediction `bú`.

The second file is intentionally retained as a failure demonstration for an
accented-vowel confusion.
